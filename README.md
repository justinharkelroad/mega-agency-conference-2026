# Mega Agency Conference 2026

A responsive redesign concept for the 2026 Mega Agency Conference in Savannah, Georgia.

## Highlights

- Animated Savannah-focused conference landing page
- Interactive three-day agenda
- Searchable attendee directory with 198 locally hosted profiles
- Sponsor gallery with 37 vendors and locally hosted brand assets
- Responsive layouts and reduced-motion support
- Registration flow prepared for a Stripe payment-link handoff

## Development

```bash
npm install
npm run dev
```

The local development server runs at `http://127.0.0.1:5173` by default.

## Production build

```bash
npm run check
npm run build
```

The production bundle is written to `dist/`.

## Stack

- React 19
- Vite 7
- Motion
- Phosphor Icons
